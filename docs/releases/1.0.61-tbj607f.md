## Implemented / 已实现

- **EN:** AirPlay receiver discovery via `_airplay._tcp` and `_raop._tcp` mDNS advertisements.
  **中文：** 通过 `_airplay._tcp` 和 `_raop._tcp` mDNS 广播进行 AirPlay 接收器发现。
- **EN:** RTSP/HomeKit-style pairing and optional PIN protection.
  **中文：** 支持 RTSP/HomeKit 风格配对及可选 PIN 保护。
- **EN:** Source paths for AAC-ELD, AAC-LC, ALAC audio, H.264 mirroring, metadata/artwork and sender remote-control events. These paths were not end-to-end playback validated for this prerelease.
  **中文：** 源码包含 AAC-ELD、AAC-LC、ALAC 音频、H.264 镜像、媒体信息/封面和发送端遥控处理路径。本预发布版未完成这些路径的端到端播放验证。
- **EN:** Foreground receiver service, receiver status/device screens, protocol settings and adaptive portrait-phone, landscape and tablet layouts, including clock and volume-control fit adjustments.
  **中文：** 包含前台接收服务、接收器状态及设备页面、协议设置，以及适配手机竖屏、横屏和平板的布局；时钟和音量控件也作了适配调整。
- **EN:** Google Cast and Miracast setup/control paths are present; media playback is unfinished.
  **中文：** 已包含 Google Cast 和 Miracast 的设置/控制路径；媒体播放尚未完成。

## Known issues and open validation / 已知问题与待验证项

- **EN:** AirPlay 2 buffered audio (type 103) is accepted by the control path but is not played.
  **中文：** AirPlay 2 缓冲音频（type 103）会被控制路径接受，但目前不会播放。
- **EN:** AirPlay audio, screen mirroring, sender interoperability and multi-room synchronization were not revalidated end to end on v64. Device discovery does not prove media playback.
  **中文：** v64 未重新完成 AirPlay 音频、屏幕镜像、发送端互通和多房间同步的端到端验证。发现设备不代表媒体播放正常。
- **EN:** Google Cast and Miracast media playback remains unfinished. FairPlay-protected streaming video cannot be decrypted by this open-source receiver; Apple Music app audio may also be protected.
  **中文：** Google Cast 和 Miracast 媒体播放仍未完成。本开源接收器无法解密 FairPlay 保护的流媒体视频；Apple Music 应用内音频也可能受到保护。
- **EN:** The full API 31 phone-emulator run is incomplete due to an ADB disconnect; no app failure was isolated from that run.
  **中文：** API 31 手机模拟器的完整测试因 ADB 断开而未完成；该次中断未能确认是应用故障。

## Potential compatibility risks / 潜在兼容性风险

- **EN:** Wi-Fi multicast filtering, AP isolation and manufacturer battery policies may affect discovery and background operation. Only the devices listed above were checked.
  **中文：** Wi-Fi 多播过滤、AP 隔离及厂商电池策略可能影响发现和后台运行；目前仅检查了上表设备。
- **EN:** Split-screen, unusual aspect ratios, custom font/display scaling and other Android OEM behaviors have not all been tested.
  **中文：** 分屏、特殊宽高比、自定义字体/显示缩放及其他 Android 厂商行为尚未全部测试。
- **EN:** Although this variant declares API 29 minimum, v64 was not revalidated on API 29 or 30; API 31 was the oldest emulator target used.
  **中文：** 虽然此变体声明最低支持 API 29，但 v64 未在 API 29/30 上重新验证；本阶段使用的最低模拟器版本为 API 31。

## Signing and update notes / 签名与更新说明

**EN:** This single APK uses the Lenovo-derived debug certificate. Existing OnePlus and emulator installations signed with other keys must be uninstalled before installing it; uninstalling deletes their local app data. Lenovo's existing test installation already uses this identity. Future local Lenovo, OnePlus and emulator debug builds share the key through the machine-local Gradle property `phairplay.debugKeystore`. The keystore stays outside version control and a single backup is maintained in OneDrive under `CodexBackups/PhAirPlay-signing/`. This is a development identity, not a production signing key.
**中文：** 本安装包使用源自 Lenovo 设备的调试证书。现有 OnePlus 和模拟器安装若由其他密钥签名，需先卸载再安装；卸载会删除应用本地数据。Lenovo 现有测试安装已使用此签名。今后 Lenovo、OnePlus 和模拟器的本地调试构建通过机器本地 Gradle 属性 `phairplay.debugKeystore` 共用此密钥。密钥文件不进入版本库，并在 OneDrive 的 `CodexBackups/PhAirPlay-signing/` 下维护一份备份。这是开发签名身份，不是正式发布密钥。
